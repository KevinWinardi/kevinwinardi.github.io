## Description

The UKMC computer laboratory information system was initiated by Klaudius Jevanda B. S., S.Kom., M.T., to help manage computer laboratory data. I served as the web developer for the admin panel, while my colleague Johannes handled the user interface.

## Key Features

- Laboratory usage schedule
- PDF report generator
- Support form for laboratory usage requests or other issues
- Roles and permissions differ for laboratory manager, dean, and head of study program
